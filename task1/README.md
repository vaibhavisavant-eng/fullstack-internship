## ✨ Features & Architecture

| Feature | Details |
|---|---|
| **Design System** | Deep purple (`#6C3FC5`) base with soft pink (`#F8A5C2`) accents, modern rounded cards & glowing borders |
| **Theme Toggle** | Light / Dark mode switcher with persistent preference in `localStorage` |
| **Typography** | Google Fonts: **Playfair Display** (headings) + **Poppins** (body text) |
| **Hero Section** | Dynamic typed role rotation, education chip, and round glowing profile photo (`profile.jpg`) |
| **About Section** | Verified professional background text & credential badges |
| **Skills** | Grouped into Frontend, Programming, Tools, and Currently Learning badges |
| **Experience** | Full Stack Development Intern role at SaiKet Systems highlighting APIs, databases, and responsive UIs |
| **Projects** | 6 curated project cards with tech tags and direct "View on GitHub" buttons |
| **Interests & Hobbies** | Interactive icon cards for Drawing, Reading, Writing, Travelling, and Journaling |
| **Contact Form** | Client-side validation: required fields, valid RFC-5322 email regex, minimum 10-character message requirement, live character count, inline errors, and animated success notification |
| **Navigation & UX** | Sticky glassmorphic navbar with active section highlight, smooth scroll, and floating "Back to Top" button |

## 🚀 How to Run

1. Open `task1/index.html` directly in any modern web browser, or
2. Use VS Code **Live Server** extension, or
3. Run a lightweight local server:
   ```bash
   # Using Python
   python -m http.server 3000

   # Or using Node
   npx serve .
   ```
4. Visit `http://localhost:3000` (or `http://localhost:4173`).
